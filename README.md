# Student Developer Portfolio Website

## Lab Title and Description
* **Lab Title:** Responsive Portfolio Website with Flexbox, CSS Grid, and Media Queries
* **Description:** This project is a one-page responsive portfolio website designed and built from scratch using HTML5 and external CSS. It showcases personal details, a story background, skills with visual progress indicators, projects, and achievements. The layout implements **Flexbox** for alignment/spacing and **CSS Grid** for structured card layouts, ensuring a clean, modern, and interactive user experience across all devices without relying on external frameworks.

---

## Steps to View Responsive Behavior

To test and view the responsive behavior of the website across different screen sizes:

1. **Open the Website:** 
   * Open `Assignmet-3.html` in any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari).
2. **Open Developer Tools:**
   * Right-click anywhere on the page and select **Inspect**, or press `F12` (Windows) / `Cmd + Option + I` (Mac).
3. **Toggle Device Toolbar:**
   * Click the **Toggle device toolbar** icon (the mobile and tablet icon in the top-left corner of the DevTools panel), or use the shortcut `Ctrl + Shift + M` (Windows) / `Cmd + Shift + M` (Mac).
4. **Test Breakpoints:**
   * Select various device presets from the dropdown menu or manually resize the viewport to test the following tested breakpoints:
     * **Mobile View (Width < 768px):** Verify that navigation links collapse neatly, the hero section stacks vertically, and grid cards adjust into a single-column layout.
     * **Tablet View (Width between 768px and 1024px):** Verify that the CSS Grid layout dynamically reorganizes cards into two columns and spacing scales smoothly.
     * **Desktop View (Width > 1024px):** Verify the full multi-column layout with side-by-side hero alignment and expanded grid rows.
